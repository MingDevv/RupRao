# RupRao (รูปเรา) — AI School Photo Search Engine
**ระบบค้นหาภาพถ่ายกิจกรรมโรงเรียนด้วยใบหน้า AI | โรงเรียนเทศบาล 6 นครเชียงราย**

RupRao (รูปเรา) เป็นแพลตฟอร์มค้นหาภาพถ่ายกิจกรรมภายในโรงเรียนด้วยเทคโนโลยีจดจำใบหน้า (Face Recognition) ช่วยให้นักเรียน ครู และผู้ปกครอง สามารถค้นหาภาพถ่ายของตนเองจากภาพกิจกรรมจำนวนมากได้ในเสี้ยววินาที เพียงแค่อัปโหลดภาพเซลฟี่ 1 รูป

---

## ✨ ฟีเจอร์หลัก (Key Features)

* **🔍 ค้นหาใบหน้าแม่นยำระดับเสี้ยววินาที:** ใช้โมเดล ArcFace สกัดลายเซ็นเวกเตอร์ใบหน้า 512 มิติ และจับคู่ความคล้ายคลึงด้วย FAISS (Vector Search Engine) อย่างรวดเร็ว
* **🏷️ ระบบตั้งชื่อบุคคลสไตล์ Google Photos:** รองรับการแท็กชื่อบุคคลจากกรอบใบหน้า และบันทึกประวัติชื่อไว้ใช้งานในเบราว์เซอร์ส่วนตัวอย่างปลอดภัย
* **⚡ แสดงผลและดาวน์โหลดรวดเร็ว:** แสดงภาพตัวอย่างด้วย WebP 640px เพื่อการโหลดที่เร็วบนมือถือ และรองรับการดาวน์โหลดไฟล์ภาพต้นฉบับความละเอียดสูง (HD) ทั้งแบบเดี่ยวและรวมไฟล์ ZIP ในคลิกเดียว
* **🛡️ มาตรฐานความปลอดภัยและความเป็นส่วนตัว (PDPA Compliance):**
  * รูปเซลฟี่ที่ใช้ค้นหาจะถูกประมวลผลบนหน่วยความจำชั่วคราว (RAM) และทำลายทิ้งทันที โดยไม่มีการบันทึกลงฮาร์ดดิสก์ (Zero-Disk Footprint)
  * มีระบบแจ้งขอลบหรือระงับการแสดงผลภาพถ่ายตามกฎหมาย PDPA (Right to be Forgotten)
* **⚙️ แดชบอร์ดผู้ดูแลระบบ (Admin Dashboard):** หน้าเว็บสำหรับครูและแอดมินในการตรวจสอบสถิติภาพรวม, จัดการอัลบั้มภาพ, อัปโหลดรูปภาพล็อตใหญ่พร้อมแถบแสดงความคืบหน้าสด (Batching Progress Bar) และตรวจสอบคำขอลบรูปภาพ

## 🛠️ สถาปัตยกรรมระบบ (Technology Stack)

* **Backend & API:** Python 3.12, FastAPI, Uvicorn, SQLite
* **AI & Machine Learning:** InsightFace (ArcFace / buffalo_l), OpenCV, FAISS (Facebook AI Similarity Search)
* **Frontend:** HTML5, Tailwind CSS, Lucide SVG Icons (Swiss Minimalist UI — ไร้ Slop)
* **Storage Engine:** 
  * `data/faces.db` — ฐานข้อมูล SQLite จัดเก็บเมทาดาทาภาพ, พิกัดกรอบใบหน้า และคำร้อง PDPA
  * `data/index.faiss` — ดัชนีเวกเตอร์สำหรับคำนวณ Cosine Similarity ระดับมิลลิวินาที
  * `data/thumbs/` — ภาพขนาดย่อ WebP สำหรับการแสดงผลหน้าเว็บ
  * `data/raw/` — ภาพกิจกรรมต้นฉบับความละเอียดสูง
